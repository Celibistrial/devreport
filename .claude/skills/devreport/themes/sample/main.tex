\begin{frame}{How it works}
\framesubtitle{One Postgres table, many workers}
\begin{itemize}
\item Jobs are rows; workers claim them with \texttt{SKIP LOCKED}.
\item Failed jobs back off and retry up to five times.
\item A Go sidecar drains dead letters into a review queue.
\item The dashboard reads the same table, so there is no second store.
\end{itemize}
\end{frame}
