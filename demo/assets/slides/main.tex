\begin{frame}{How it works}
\drFlow{Node service, Postgres jobs table, Worker pool, Go sidecar, Review queue}[enqueues a row, one row per job, claims with \texttt{SKIP LOCKED}, takes dead letters, manual retry]
\begin{itemize}
\item Jobs are rows, so two workers never take the same job and no lock server is needed.
\item Failed jobs back off and retry up to five times before the sidecar takes them.
\end{itemize}
\end{frame}
